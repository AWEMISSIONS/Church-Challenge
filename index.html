Privacy & usage tracking

We use a random ID stored in this browser to count app visits, resource opens, game starts, and completions. We store only the app, event, and date. We do not collect names, location, prayer requests, comments, or Bible notes. Each app has a separate ID. Clearing browser storage may make a returning visitor appear new. Turning analytics off stops future tracking; reset removes this app’s stored ID and its event records.

Usage analytics are on for this browser.
